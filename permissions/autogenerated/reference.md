## Default Permission

Permite consultar o uso de aplicativos no Android. A concessão da permissão especial ainda depende do usuário.

#### This default permission set includes the following:

- `allow-check-permission`
- `allow-request-permission`
- `allow-get-all-app-usage`
- `allow-get-app-usage`
